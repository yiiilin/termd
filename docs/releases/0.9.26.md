termd 0.9.26

用户可见变化:
- 修复移动端打开浏览器窗口（VNC 画面）后无法输入的问题：点击画面现在会唤起系统软键盘，按键（含中文等输入法组合）会发送到远程浏览器；桌面端行为不变。
- 需要移动端浏览器（iOS/Android）访问浏览器窗口页面，点击画面后软键盘弹出即可输入。

兼容性:
- workspace、前端和发布资产版本同步到 `0.9.26`；daemon 与 Web UI 建议同步升级，termrelay 和 termctl 可按正常版本节奏同步更新。
- 本次只调整浏览器窗口前端交互，不改变配置、持久化数据、终端协议主版本、RFB 协议或 supervisor 兼容版本（`2026-07-12-dual-ws`）。
- 普通升级不会清空或主动终止已有终端会话；现有 supervisor 和 session runtime 保持原有兼容规则。
