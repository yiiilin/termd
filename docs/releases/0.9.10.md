termd 0.9.10

用户可见变化:
- 版本更新弹窗新增「检测版本」按钮：点击后立即强制查询 GitHub 最新版本（跳过本地一小时缓存），可随时确认是否有新版本。
- 「立即更新」按钮现在受连接状态控制：未连接 daemon 时按钮禁用并提示「需连接 daemon 后才能更新」，连接就绪后自动可点，避免在无连接时点击更新无响应。

兼容性:
- workspace、前端和发布资产版本同步到 `0.9.10`；daemon 与 Web UI 建议同步升级，termrelay 和 termctl 可按正常版本节奏同步更新。
- 本次只调整前端版本弹窗交互，不改变配置、持久化数据、终端协议主版本或 supervisor 兼容版本（`2026-07-12-dual-ws`）。
- 普通升级不会清空或主动终止已有终端会话；现有 supervisor 和 session runtime 保持原有兼容规则。
