termd 0.9.6

用户可见变化:
- 修复服务器状态面板的 CPU 指标「一动不动」：此前展示的是系统开机以来的平均占用率（长时间窗口内几乎恒定），现在改为间隔采样（每 10 秒推送一次时计算两次采样间的占用增量），CPU 数值和曲线随负载实时波动，与 top 的显示口径一致。首次采样前显示 0，随后按推送节奏更新。

兼容性:
- workspace、前端和发布资产版本同步到 `0.9.6`；daemon 与 Web UI 建议同步升级，termrelay 和 termctl 可按正常版本节奏同步更新。
- 本次只修正 daemon 状态面板的 CPU 采样口径，不改变配置、持久化数据、终端协议主版本或 supervisor 兼容版本（`2026-07-12-dual-ws`）。
- 普通升级不会清空或主动终止已有终端会话；现有 supervisor 和 session runtime 保持原有兼容规则。
