termd 0.9.20

用户可见变化:
- 修复经 relay 访问页面时版本弹窗的更新按钮无效的问题：此前 relay 不转发 `/api/update/*` 请求，经 relay 打开页面（如 http://host:8080）点击「立即更新」（termd 或 relay 行）会得到 404；现在 relay 会把更新请求转发给 daemon，两个组件的更新按钮在 relay 页面均可正常使用。

兼容性:
- workspace、前端和发布资产版本同步到 `0.9.20`；daemon 与 Web UI 建议同步升级，termrelay 和 termctl 可按正常版本节奏同步更新。
- 本次只调整 relay 的 HTTP 转发路径，不改变配置、持久化数据、终端协议主版本或 supervisor 兼容版本（`2026-07-12-dual-ws`）。
- 普通升级不会清空或主动终止已有终端会话；现有 supervisor 和 session runtime 保持原有兼容规则。
