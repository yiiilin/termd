termd 0.9.11

用户可见变化:
- 修复自动更新在慢速或受限网络下失败的问题：更新器现在读取标准环境变量代理（`HTTPS_PROXY`/`HTTP_PROXY`/`ALL_PROXY` 及其小写变体，`NO_PROXY` 排除内网直连），并通过代理下载 release 资产；下载总超时从 120 秒放宽到 30 分钟，慢速但持续的下载（如 200KB/s 下 50MB）不再被误杀。
- 修复更新失败完全静默的问题：后台更新（下载/替换/重启）的结果现在写入 daemon 日志（`termd update applied` / `termd update failed`），失败时能查到具体原因。

兼容性:
- workspace、前端和发布资产版本同步到 `0.9.11`；daemon 与 Web UI 建议同步升级，termrelay 和 termctl 可按正常版本节奏同步更新。
- 本次只调整自动更新行为，不改变配置、持久化数据、终端协议主版本或 supervisor 兼容版本（`2026-07-12-dual-ws`）。
- 普通升级不会清空或主动终止已有终端会话；现有 supervisor 和 session runtime 保持原有兼容规则。
- 需要代理访问 GitHub 的环境，请在 daemon 的 systemd 环境（如 `termd.env`）中配置 `HTTPS_PROXY` 等变量后重启 daemon；已有配置无需迁移。
