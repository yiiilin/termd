termd 0.9.9

用户可见变化:
- Web 终端支持粘贴图片：复制图片后在终端 Ctrl+V，浏览器把图片上传到 daemon（保存到当前 session 工作目录，文件名 `termd-paste-<时间戳>.<扩展名>`），自动把单引号包裹的路径插入输入，并显示预览条；同时尽力写入 daemon 系统剪贴板——Codex 等基于 arboard 的 agent 在终端里按 Ctrl+V 即可直接附加图片。omp 用 `@路径`、Claude Code 用 `/add 路径` 引用。图片格式白名单（PNG/JPEG/WebP/GIF），超过 7 天的粘贴文件自动清理。
- 切换 session 时终端表面不再闪空屏：清屏到新画面渲染之间用遮罩盖住，内容直接替换；attach 失败时 6 秒后自动恢复显示。
- 工作台顶栏与浏览器查看器的操作按钮统一为常驻边框样式（浏览器/设置/客户端/守护进程，以及浏览器查看器的四个操作按钮）。
- 「客户端」列表从下拉面板改为居中模态框，点击外部、Esc 或关闭按钮均可关闭。

兼容性:
- workspace、前端和发布资产版本同步到 `0.9.9`；daemon 与 Web UI 建议同步升级，termrelay 和 termctl 可按正常版本节奏同步更新。
- 本次新增粘贴图片保存端点与前端交互，不改变配置、持久化数据、终端协议主版本或 supervisor 兼容版本（`2026-07-12-dual-ws`）。
- 普通升级不会清空或主动终止已有终端会话；现有 supervisor 和 session runtime 保持原有兼容规则。
