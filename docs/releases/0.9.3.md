termd 0.9.3

用户可见变化:
- 修复 `termd upgrade`、`termrelay upgrade` 和 `termctl upgrade` 在 Linux 上执行已验证候选程序时可能报 `Text file busy` 的问题；下载完成后会先关闭可写文件句柄，再执行版本校验和安装。
- 自升级回归测试现在会真实执行候选程序的 `--version` 与 `install --yes` 路径，并确认升级结束后临时文件会自动清理。

兼容性:
- workspace、前端和发布资产版本同步到 `0.9.3`；daemon、Web UI、termrelay 和 termctl 建议同步升级。
- 本次仅修复共享自升级器，不改变协议、配置、持久化数据或 supervisor 兼容版本；普通升级不会清空或终止已有终端会话。
- 候选程序仍需通过 release 资产大小和 SHA-256 校验后才会获得执行权限，原有发布校验与原子安装流程保持不变。
