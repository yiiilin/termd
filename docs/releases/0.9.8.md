termd 0.9.8

用户可见变化:
- 版本号徽标现在显示 daemon 的**实际运行版本**（来自 daemon 状态），不再使用前端构建版本；经 relay 访问时（如 `termd.yiln.de` 页面）额外显示 Relay 版本行，两个组件各自与 GitHub 最新版本对比、各自显示更新提示（黄色小点）。
- 版本弹窗新增「立即更新」按钮：termd 页面点击后 daemon 自动下载对应架构的 GitHub release 构建、校验版本、备份旧二进制、替换并重启服务；经 relay 时 Relay 行同样可一键更新（由 daemon 用 admission 凭证委托 relay 执行，浏览器不接触 relay 主机凭证）。更新受理后页面自动刷新，重启期间连接短暂中断。
- 更新失败会自动回滚到更新前的二进制；同一主机同一时刻只允许一个更新流程。

兼容性:
- workspace、前端和发布资产版本同步到 `0.9.8`；daemon 与 Web UI 建议同步升级。relay 需升级到本版本才能获得 `/version` 与受限更新端点；旧 relay 下页面按直连场景显示（只显示 termd）。
- 本次新增版本上报与更新端点，不改变配置、持久化数据、终端协议主版本或 supervisor 兼容版本（`2026-07-12-dual-ws`）。
- 普通升级不会清空或主动终止已有终端会话；现有 supervisor 和 session runtime 保持原有兼容规则。
