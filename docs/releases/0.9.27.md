termd 0.9.27

用户可见变化:
- 移动端浏览器窗口的键盘改为显式开关：点击画面不再自动弹出软键盘（画面点击保持鼠标语义，避免误弹和遮挡）；点击工具栏的键盘按钮打开/收起系统软键盘，按钮高亮显示键盘开启状态。
- 桌面端工具栏键盘按钮保持原有「发送 Ctrl+Alt+Delete」功能不变。

兼容性:
- workspace、前端和发布资产版本同步到 `0.9.27`；daemon 与 Web UI 建议同步升级，termrelay 和 termctl 可按正常版本节奏同步更新。
- 本次只调整浏览器窗口前端的键盘交互，不改变配置、持久化数据、终端协议主版本、RFB 协议或 supervisor 兼容版本（`2026-07-12-dual-ws`）。
- 普通升级不会清空或主动终止已有终端会话；现有 supervisor 和 session runtime 保持原有兼容规则。
