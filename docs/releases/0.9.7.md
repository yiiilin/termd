termd 0.9.7

用户可见变化:
- 版本号（守护进程管理页顶栏与工作台侧边栏）升级为可点击的版本徽标：后台每小时探测一次 GitHub 最新 release（首次加载延迟 3 秒，结果本地缓存 1 小时，探测失败静默不打扰），发现新版本时版本号右上角显示黄色小点。
- 点击版本号弹出「版本更新」小窗：显示当前版本、最新版本与状态说明（发现新版本 / 已是最新 / 正在检查 / 无法获取），并提供「查看 GitHub Release」链接，点击在新标签页打开对应版本的 release 页面，可直接下载新构建。
- 该功能同样覆盖 relay 的 Web 页面（termrelay --web 嵌入同一前端）；daemon 与 relay 升级到本版本后页面都会具备版本提示能力。

兼容性:
- workspace、前端和发布资产版本同步到 `0.9.7`；daemon 与 Web UI 建议同步升级，termrelay 和 termctl 可按正常版本节奏同步更新。
- 本次只新增前端版本提示，不改变配置、持久化数据、终端协议主版本或 supervisor 兼容版本（`2026-07-12-dual-ws`）。
- 普通升级不会清空或主动终止已有终端会话；现有 supervisor 和 session runtime 保持原有兼容规则。
