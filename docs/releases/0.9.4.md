termd 0.9.4

用户可见变化:
- 会话列表现在识别 `oh-my-pi`（`omp`）的运行、需要操作、完成和就绪状态，并在列表中显示低强调的就绪状态，便于从多个会话中快速判断 AI Agent 进度。
- 桌面端会话列表支持从右边缘拖动或用方向键调整宽度；过长的会话标题保持单行并自动省略，完整标题可通过悬停查看。
- Web 终端短暂断线或浏览器恢复时会更严格地淘汰过期的 metadata/terminal 连接，避免旧 WebSocket 与新连接并行读取，降低重复 challenge、access token 刷新和终端重连卡顿的概率。
- 浏览器控制台新增终端连接生命周期诊断信息，可区分主动替换、服务端关闭、网络断开和心跳事件；日志只包含连接标识与状态元数据，不记录 access token 或终端输入内容。

兼容性:
- workspace、前端和发布资产版本同步到 `0.9.4`；为了完整显示 `oh-my-pi` 状态，daemon 与 Web UI 建议同步升级，termrelay 和 termctl 可按正常版本节奏同步更新。
- 本次只新增向后兼容的 AI Agent 状态标识和前端连接管理改进，不改变配置、持久化数据、终端协议主版本或 supervisor 兼容版本。
- 普通升级不会清空或主动终止已有终端会话；现有 supervisor 和 session runtime 保持原有兼容规则。
