termd 0.8.20

用户可见变化:
- 可以基于一个正在运行的 session 当前工作目录创建新 session；新终端会继承来源 session 的实时目录，适合在同一个项目目录中并行打开工作会话。
- 桌面端的新建按钮增加“在当前目录新建”，session 行的操作菜单也可以从任意运行中 session 的目录创建；移动端工作区菜单提供相同入口。
- 创建过程使用独立终端连接，创建失败时不会打断原 session；来源 session 已停止、目录被删除或不可访问时会明确提示，不会偷偷回退到默认目录。
- direct daemon 和 trusted relay 共用 `terminal.create_in_session_cwd` 协议路径，并补充成功、失败、目录替换和持久化恢复回归覆盖。

兼容性:
- workspace、Cargo lockfile 和 Web 前端版本同步到 `0.8.20`。
- 新增 `terminal.create_in_session_cwd` terminal WebSocket 命令；旧客户端仍可继续使用原有 `terminal.create` 和 `terminal.attach`。
- supervisor 兼容版本保持 `2026-07-12-dual-ws`；从 0.8.19 普通升级不会清空或终止已有 live session。
- GitHub Release 继续只发布 `termd`、`termctl`、`termrelay` 的 Linux amd64/arm64 六个裸二进制，不构建或推送容器镜像。
