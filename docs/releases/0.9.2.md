termd 0.9.2

用户可见变化:
- 修复浏览器 runtime 发布归档在 termd 安装时失败的问题；归档中的 hard link 现在会在打包阶段展开为普通文件，运行时解包器可以正常安装 TigerVNC/Openbox runtime。
- 发布流水线新增 runtime 归档验收：普通文件和目录可以发布，hard link、symbolic link 及损坏归档会在上传前被拒绝，避免再次生成不可安装的 runtime 资产。

兼容性:
- workspace、前端和发布资产版本同步到 `0.9.2`；daemon、Web UI、termrelay 和 termctl 建议同步升级。
- 仅修复 runtime 归档格式与发布校验，不改变终端、relay、browser session 或现有 pairing/session 数据；普通升级不会清空已有会话。
- 浏览器 runtime 仍按架构分别提供 amd64/arm64 归档，最低 glibc 基线保持不变。
