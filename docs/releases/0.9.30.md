termd 0.9.30

用户可见变化:
- 修复会话 git 面板对含失效 worktree 的仓库显示为空的问题：当仓库的 worktree 登记项指向已删除/移动的目录（例如清理过的临时构建目录）时，`git worktree list` 会把这些条目标记为可清理，但面板此前仍会对其执行状态检查，任一失败就导致整个 git 快照返回错误、面板变空。现在失效条目会在解析阶段被跳过，面板只展示真实存在的 worktree，且不修改仓库本身的 git 状态。
- 修复 git 快照请求的专属超时此前未实际生效的问题：上一版本为 git 请求设置的更长超时窗口因默认请求包装未传递超时参数而被丢弃，始终回退到普通请求超时；现在 git 面板请求在 worktree 较多、仓库较大的情况下也能等待足够的时间完成全部状态检查。

兼容性:
- workspace、前端和发布资产版本同步到 `0.9.30`；daemon 与 Web UI 建议同步升级，termrelay 和 termctl 可按正常版本节奏同步更新。
- 本次只调整 git 面板的读取与过滤逻辑，不改变配置、持久化数据、终端协议主版本或 supervisor 兼容版本（`2026-07-12-dual-ws`）。
- 普通升级不会清空或主动终止已有终端会话；现有 supervisor 和 session runtime 保持原有兼容规则。
