termd 0.9.29

用户可见变化:
- 修复会话 git 面板在 worktree 数量多或分支较多时显示为空的问题：此前每个 worktree 的 `git status` 串行执行，worktree 一多总耗时超过前端请求超时，整个 git 面板就变成空白。现在各 worktree 的状态检查并行执行，daemon git 命令超时放宽，前端 git 请求超时也相应加长，面板在仓库结构复杂时也能正常加载。

兼容性:
- workspace、前端和发布资产版本同步到 `0.9.29`；daemon 与 Web UI 建议同步升级，termrelay 和 termctl 可按正常版本节奏同步更新。
- 本次只调整 git 面板的读取与超时策略，不改变配置、持久化数据、终端协议主版本或 supervisor 兼容版本（`2026-07-12-dual-ws`）。
- 普通升级不会清空或主动终止已有终端会话；现有 supervisor 和 session runtime 保持原有兼容规则。
