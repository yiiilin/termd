termd 0.9.28

用户可见变化:
- 修复切换会话后终端屏幕会再次刷新 1-2 秒的问题：切换会话后自动拉取滚动历史的动作不再「断开连接 + 清屏重放」，而是在当前连接上直接获取带历史的快照并静默写入，屏幕内容不重置、不闪烁，向上滚动即可看到历史。

兼容性:
- workspace、前端和发布资产版本同步到 `0.9.28`；daemon 与 Web UI 建议同步升级，termrelay 和 termctl 可按正常版本节奏同步更新。
- 本次新增 daemon 的 HTTP control 端点（`session.terminal_snapshot`，由前端自动调用），不改变配置、持久化数据、终端协议主版本或 supervisor 兼容版本（`2026-07-12-dual-ws`）。
- 普通升级不会清空或主动终止已有终端会话；现有 supervisor 和 session runtime 保持原有兼容规则。
