termd 0.9.5

用户可见变化:
- 设置里新增「上送分析日志」开关（默认关闭）：开启后浏览器页面的终端诊断事件（重连、snapshot 重绘、输入输出、连接生命周期等）批量回传到 termd daemon 日志，排查终端闪烁、断连等疑难问题时可直接从 journalctl 按设备过滤，无需现场抓浏览器控制台。上送前会递归剥离 token、密钥、签名、预览等敏感字段。
- 修复 Web 终端周期性「闪一下」：access token 换发时不再重连健康的 metadata/terminal WebSocket，消除了每 3 分钟左右一次的快照整屏重绘；若任何原因的重连内容与已渲染内容一致（同序号、同大小且非历史拉取），也直接续写而不清屏重绘。
- 修复服务器状态面板不刷新：daemon 现在每 10 秒采样一次 CPU/内存/磁盘/网络并推送给 Web 页面（此前依赖 token 换发时的连接重建，修复闪烁后该隐式刷新消失），状态曲线刷新粒度比之前更细。

兼容性:
- workspace、前端和发布资产版本同步到 `0.9.5`；daemon 与 Web UI 建议同步升级，termrelay 和 termctl 可按正常版本节奏同步更新。
- 本次只新增向后兼容的诊断上送消息与状态推送，不改变配置、持久化数据、终端协议主版本或 supervisor 兼容版本（`2026-07-12-dual-ws`）。
- 普通升级不会清空或主动终止已有终端会话；现有 supervisor 和 session runtime 保持原有兼容规则。
