# Use cookie-bound native downloads for file offers

File Offers have no artificial size limit, including on iPhone and other browsers without the File System Access API. After an authenticated client prepares a download, termd issues a short-lived single-use `HttpOnly`, `SameSite=Strict` bearer cookie and returns a non-authorizing download ID; native browser navigation can then stream a non-cacheable attachment without putting a credential in the URL or buffering the file in JavaScript memory. The normal deployment is same-origin and same-site development origins are supported with credentialed CORS. Cross-site third-party-cookie delivery is outside the contract. Copying the complete grant cookie transfers its remaining one-time authority; the design does not claim hardware or non-exportable browser binding.
